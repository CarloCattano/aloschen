To keep the C code clean and catch potential bugs early, we use Clang\textquotesingle{}s tools.


\begin{DoxyEnumerate}
\item {\bfseries{Run scan-\/build once}} – execute from {\ttfamily source/\+}:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{cd\ source\ \&\&\ make\ scan}

\end{DoxyCode}
 This invokes {\ttfamily scan-\/build} a single time (no recursive Make invocation) with {\ttfamily SCAN\+\_\+\+OPTS} available for extra flags. If the binary is missing the target prints a message and exits successfully.
\item {\bfseries{Inspect warnings}} – the analyzer will report dead stores, uninitialized values, etc. Address each warning by reading the source, and when safe, rewrite the code to remove the warning rather than silence it.
\item {\bfseries{Repeat as needed}} – rerun {\ttfamily make scan} after each fix until the output reports no bugs, or not too important warnings (an empty report directory). Since the rule is non‑fatal,
\item {\bfseries{Clang‑tidy for style}} – use {\ttfamily make tidy} which runs {\ttfamily clang-\/tidy} over all {\ttfamily .c}/\+{\ttfamily .cpp} files, using a {\ttfamily compile\+\_\+commands.\+json} if one exists. Again, missing {\ttfamily clang-\/tidy} is tolerated.
\end{DoxyEnumerate}

These targets are part of the regular {\ttfamily Makefile.\+mk} and are optional helpers.

Additional analysis can be performed with cppcheck
