ALOSCHEN is a lightweight, mistake-\/resistant looper that stays locked to the host transport. It provides {\bfseries{3 independent loop slots}}, each with {\bfseries{one-\/shot}} record/\+overdub and {\bfseries{quantized undo}}.

Tested on amd64 and aarch64 (MOD).

\hypertarget{md_README_autotoc_md8}{}\doxysection{\texorpdfstring{Quick start}{Quick start}}\label{md_README_autotoc_md8}

\begin{DoxyEnumerate}
\item Start the host transport (this plugin is transport-\/synced; it does not free-\/run).
\item Set {\ttfamily Bars} (loop length = {\ttfamily Bars} bars).
\item Press {\ttfamily Loop1}/\+{\ttfamily Loop2}/\+{\ttfamily Loop3}:\+
\begin{DoxyItemize}
\item If the slot is empty:\+ arms base recording.
\item If the slot has audio:\+ arms an overdub.
\end{DoxyItemize}
\item Recording starts {\bfseries{quantized}} and lasts for exactly {\bfseries{one loop length}}, then auto-\/stops.
\end{DoxyEnumerate}\hypertarget{md_README_autotoc_md9}{}\doxysection{\texorpdfstring{Looping behavior}{Looping behavior}}\label{md_README_autotoc_md9}
Per slot:\+


\begin{DoxyItemize}
\item {\bfseries{Arm (base)}}:\+ Press {\ttfamily LoopN} when the slot is empty.
\begin{DoxyItemize}
\item If this is the {\bfseries{first base recording in the instance}} (no loop origin yet):\+ starts on the {\bfseries{next Bars-\/cycle downbeat}} (bar 1 beat 1 /\+ step 0).
\item Otherwise:\+ starts on the {\bfseries{next loop boundary}} (phase-\/aligned with the existing loop origin).
\end{DoxyItemize}
\item {\bfseries{Arm (overdub)}}:\+ Press {\ttfamily LoopN} when the slot already has audio.
\begin{DoxyItemize}
\item Starts on the {\bfseries{next loop boundary}}, records one loop length, then commits as a new overdub layer.
\end{DoxyItemize}
\item {\bfseries{One-\/shot}}:\+ base and overdub both record for exactly one loop length and auto-\/stop.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md10}{}\doxysubsection{\texorpdfstring{Undo}{Undo}}\label{md_README_autotoc_md10}

\begin{DoxyItemize}
\item Undo is {\bfseries{quantized}} to the next {\bfseries{bar downbeat}}.
\item Press {\ttfamily UndoN} once:\+ removes one overdub layer at the next bar.
\item Press {\ttfamily UndoN} rapidly (2+ times before the next bar):\+ clears the whole slot at the next bar.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md11}{}\doxysubsection{\texorpdfstring{Bars changes (important)}{Bars changes (important)}}\label{md_README_autotoc_md11}
Changing {\ttfamily Bars} is treated as a {\bfseries{blocking resync}} (similar to disable/\+enable):\+


\begin{DoxyItemize}
\item The engine resets to guarantee transport/\+phase correctness.
\item Existing loops/\+arms are cleared.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md12}{}\doxysection{\texorpdfstring{Controls}{Controls}}\label{md_README_autotoc_md12}
Main controls:\+


\begin{DoxyItemize}
\item {\ttfamily Bars} (1..32, integer):\+ loop length in bars.
\item {\ttfamily Click} (0..10, integer):\+ click volume (only when no loops are playing).
\item {\ttfamily Mix} (0..100, integer):\+ dry/\+wet blend.
\item {\ttfamily ENABLED} (0/\+1):\+ resets engine state on disable.
\end{DoxyItemize}

Per-\/slot buttons:\+


\begin{DoxyItemize}
\item {\ttfamily Loop1}, {\ttfamily Loop2}, {\ttfamily Loop3}:\+ arm base/\+overdub.
\item {\ttfamily Undo1}, {\ttfamily Undo2}, {\ttfamily Undo3}:\+ quantized undo/\+clear.
\end{DoxyItemize}

Per-\/slot playback volumes:\+


\begin{DoxyItemize}
\item {\ttfamily loop1\+\_\+vol}, {\ttfamily loop2\+\_\+vol}, {\ttfamily loop3\+\_\+vol} (0..1, float):\+ playback gain coefficients.
\begin{DoxyItemize}
\item Default {\ttfamily 1.\+0} = unity gain (no change).
\item Applies to playback (base + overdub layers), not recording.
\end{DoxyItemize}
\end{DoxyItemize}

MIDI:\+


\begin{DoxyItemize}
\item {\ttfamily MIDI Base} sets the note mapping:\+
\begin{DoxyItemize}
\item {\ttfamily MIDI Base + 0..2} → {\ttfamily Loop1..3}
\item {\ttfamily MIDI Base + 3..5} → {\ttfamily Undo1..3}
\end{DoxyItemize}
\end{DoxyItemize}\hypertarget{md_README_autotoc_md13}{}\doxysection{\texorpdfstring{Click + step indicator}{Click + step indicator}}\label{md_README_autotoc_md13}

\begin{DoxyItemize}
\item The click has three sounds:\+
\begin{DoxyItemize}
\item {\bfseries{START}}:\+ bar 1 beat 1 of the Bars-\/length cycle (once per cycle)
\item {\bfseries{HIGH}}:\+ beat 1 of other bars
\item {\bfseries{LOW}}:\+ all other beats
\end{DoxyItemize}
\item The DSP also outputs {\ttfamily bar\+\_\+step} (index 20) as a step index across the Bars-\/length cycle:\+
\begin{DoxyItemize}
\item steps = {\ttfamily Bars \texorpdfstring{$\ast$}{*} 4} (4 steps per bar)
\item range is sized for {\ttfamily Bars} up to 32 (max 127)
\end{DoxyItemize}
