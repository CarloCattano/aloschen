# To auto-format all C/C++ files in this repo using clang-format:
# Run this from the repo root:
#
#   clang-format -i source/*.c source/*.h
#
# Or recursively for all files:
#   find source -name '*.c' -o -name '*.h' | xargs clang-format -i
#
# Requires clang-format installed (sudo apt install clang-format)
#
# The .clang-format file in repo root enforces canonical style.
